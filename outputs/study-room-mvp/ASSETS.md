# Public source edition

The public repository includes the application source, but not audio files or
raster image assets pending provenance review. Missing scene, avatar and pet
images must be supplied separately with appropriate rights for a full visual
demo. The original local development copy retains its images.

Runtime paths are declared in app.js, account.js, companion.js and
scene-effects.js. Do not replace these files with unlicensed third-party media.
SVG icons retain their existing license in assets/lucide-LICENSE.
