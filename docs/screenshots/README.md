# Product screenshots

Twenty-four screenshots supplied by the project author on October 17, 2026.
They cover home, session resume, scenes, sound, session setup, focused work,
manual todos, plan import and review, AI assistance, task execution, and the
calendar-based task inbox, pet growth and adoption, daily check-ins, diaries,
sign-in, registration, and avatar selection. These are product demonstrations,
not evidence of model quality. The check-in encouragement currently uses a fixed
message rather than personalized daily generation.

Screenshots do not grant separate rights to reuse the underlying visual assets.
